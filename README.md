# arabianprinceee.github.io

Forwards the old addresses of PetPill's website, `arabianprinceee.github.io/petpill/…`, to the
same page on https://petpillapp.com (language, query and `#anchor` kept). `petpill/` holds one
page for each page the site had; `404.html` covers any other `/petpill/` address.

**Keep this repo public, with Pages on.** The site's repo was renamed `petpill` → `petpill-web`
on 10 November 2026, and GitHub Pages does not follow a rename. The App Store listing of PetPill
2.4 and earlier links to these addresses.

The site itself: https://github.com/arabianprinceee/petpill-web
